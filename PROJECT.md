# Проект: Портфолио-сайт (Архитектура Проекта)

## Описание
Многостраничный статический сайт (HTML+CSS), объединяющий 5 направлений деятельности владельца. Основной акцент — IT-разработка (конфигураторы, автоматизация). Остальные направления — конструкторские услуги, мебель на заказ, домокомплекты из фанеры, строительство.

## Ключевое решение: связь направлений
Все направления работают как единая экосистема. IT-раздел — «ядро», остальное — демонстрация и применение IT-разработки.

## Принятые архитектурные решения

1. **Сайт = статический HTML+CSS**, без сборки. Простота деплоя на GitHub Pages.
2. **Каждое направление — самостоятельный лендинг** со своими контактами. Рекламируются отдельно. Кросс-ссылки между направлениями — второстепенны (блок «Также у нас»).
3. **Главная страница = IT-лендинг** (основное направление) + блок «Также мы делаем» со ссылками на остальные лендинги.
4. **Конфигуратор Outline3D убрать** — заменить на анонс/заглушку под свой конфигуратор (когда будет готова клиентская версия).
5. **Разные бренды допустимы**: IT — «Архитектура Проекта» (временно), остальное — существующие названия.
6. **Русский язык**, мультиязычность не нужна сейчас.
7. **Хостинг**: GitHub Pages (бесплатно, 1 ГБ, у владельца уже есть проект на GitHub).
